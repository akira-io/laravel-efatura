# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [Unreleased]

### Breaking Changes

- The minimum runtime is now PHP 8.5 with Laravel 13.
- The test toolchain now requires Pest 5.
- The production branch is now `main`; the `1.x` branch is retired.

### Changed

- Documentation now follows the Akira package README structure.
