All notable changes to `akira/efatura` will be documented in this file.

### Breaking Changes

- The minimum runtime is now PHP 8.5 with Laravel 13.
- The test toolchain now requires Pest 5.
- The production branch is now `main`; the `1.x` branch is retired.
