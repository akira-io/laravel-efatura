# Contributing to Laravel Efatura

## Bugs and Feature Requests

Open an issue at https://github.com/akira-io/laravel-efatura/issues. Include:

- What you expected to happen.
- What happened.
- A minimal reproduction.
- Versions for `akira/efatura`, PHP, Laravel, and the operating system.

## Pull Requests

1. Fork the repository and create a branch from `main`.
2. Add or update tests for the change.
3. Run the full test command from the README before pushing.
4. Use conventional commit messages. Release notes and the changelog are generated from them via `git-cliff`.
5. Open the pull request against `main`.

## Style

- Match the existing project conventions.
- Keep feature work, refactors, and dependency bumps in separate pull requests.
- Do not use emojis in code, documentation, commit messages, or pull request descriptions.
