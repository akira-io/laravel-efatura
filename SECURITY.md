# Security Policy

## Reporting a Vulnerability

Report security vulnerabilities by email to [kidiatoliny@gmail.com](mailto:kidiatoliny@gmail.com). Do not open a public issue.

We will acknowledge receipt within 72 hours and provide a response within 7 days with the next steps.

## Disclosure Policy

We follow coordinated disclosure. After a fix is released, we publish a security advisory on GitHub with credit to the reporter unless they prefer to remain anonymous.

## Supported Versions

| Version | Status |
|---------|--------|
| 1.x     | Supported |
| Older   | Best-effort backports for critical issues |
